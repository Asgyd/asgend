Nodes

Точки размещения моделей: локальное устройство, локальная сеть или удалённый endpoint.

Загрузка nodes…

Для каждого узла задайте endpoint и api_type: openai_compatible или systemone. System One использует типизированный контракт /v1/systemone. Удалённые узлы рекомендуется подключать только через HTTPS, с проверенными TLS-сертификатами и секретами вне репозитория.

Профили исполнения и конфигурация сервера

Пользовательские профили описывают инструкции и разрешения; встроенных ролей coder/planner/reviewer нет. Системные настройки — в config/config.json.

Не загружено

Поле model_id привязывает профиль к модели в Nodes. Не добавляйте инструменты в allow-list без соответствующей проверки доступа.

Сохранённые настройки загружаются после перезапуска сервера. Файлы инструкций селекторов находятся в ~/.config/asgend/instructions/ и читаются заново для каждого задания.

Dynamic resource selection

Для каждого задания decision-модель параллельно классифицирует актуальные Markdown-файлы четырьмя независимыми инструкциями.

Загрузка каталога ресурсов…

Содержимое каталогов перечитывается на каждом запросе классификации: добавленные Markdown-файлы становятся доступными без перезапуска. Если decision-модель выключена или ответ невалиден, применяется ограниченный fallback к настройкам профиля исполнения.

Instructions

Эти файлы определяют только собственную классификационную задачу и не содержат фиксированный список ресурсов.

~/.config/asgend/instructions/select_skills.md
~/.config/asgend/instructions/select_system_prompts.md
~/.config/asgend/instructions/select_tools.md
~/.config/asgend/instructions/select_knowledge.md

Шаблоны используют динамические placeholders: {{TASK}}, {{AGENT}}, {{RESOURCE_TYPE}}, {{FILES}}. При первом запуске создаются только отсутствующие файлы; пользовательские инструкции не перезаписываются.
