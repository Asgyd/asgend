# Planning skill

1. Restate the desired outcome and identify the deliverable.
2. Separate explicit requirements from assumptions and unknowns.
3. Break the work into steps with one clear responsibility each.
4. Add an observable acceptance criterion to each step.
5. Identify dependency order, failure modes and an inexpensive verification path.
6. Do not turn a non-blocking ambiguity into an unnecessary user question; state the assumption instead.
